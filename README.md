# Jay Label Maker

Web app for printing labels on a Brother PT-P300BT (P-touch Cube) using Web Serial over Bluetooth.

- Live: https://doneduardo.github.io/JayLabelMaker/
- Local dev: `python3 -m http.server 8000`, then open http://localhost:8000 in Chrome.

See `CLAUDE.md` for protocol notes and the build plan.
